# Agallas · Carta digital

Carta pública de Agallas Barra Cevichera, adaptada a celulares. Incluye categorías y buscador. Cada plato muestra nombre, descripción y precio en soles.

## Publicación

Activar GitHub Pages desde Settings > Pages, con Deploy from a branch, rama main y carpeta / (root).

## Actualizar platos

Editar menu-data.js. Los estilos están en style.css y responsive.css.
